Adding a new project? Save its screenshot here and set "image" in js/data/projects.js
to "assets/images/your-file-name.jpg". Phone screenshots and app windows: also add fit: "whole"
so they're shown in full instead of cropped.
Tip: compress images (for example with squoosh.app) to under about 300 KB each so the site loads fast.
